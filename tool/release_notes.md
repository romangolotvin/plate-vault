# Plate Vault 1.8.0

## Fix
- Белый/пустой экран на главной: убрана анимация Opacity при смене вкладок
- Скан: кнопка «Снять два ракурса» снова видна (фикс с 1.7.1)

## Профиль и витрина
- Вкладка **Витрина** — до 6 лучших Street (раньше «Сейф»)
- Вкладка **Профиль** — вся твоя коллекция, аватар из галереи, год регистрации, страна с флагом
- Удаление номера только после подтверждения «Да / Нет»
- Из «Мир» можно открыть чужой профиль
- Настройки — шестерёнка в профиле

## Install / OTA
1. Установи APK или **Настройки → Проверить обновления**
2. Разреши установку из этого источника, если Android спросит
